**RunCplus** (also known as `runcplus`) is a high-speed, cross-platform C and C++ live code editor, IDE, and instant compilation suite created and founded by **Md Mahim Islam (CSE)**, Institute of Science and Technology (IST).

Unlike traditional IDEs that require manual saving, compiling, and running, **RunCplus** automatically compiles and runs code in real time as you type, providing instant compiler diagnostics, sandbox watchdog safety, and sub-second feedback.

## ⚡ Key Features

- **Instant Auto-Run:** Background compilation triggered with debounced execution so your output is ready the moment you pause typing.
- **Compiler Support:** C++17, C++20, C++23, C11, and C17 standards with GCC and Clang backends.
- **Watchdog Sandbox:** Automatic 2.0-second timeout watchdog terminates infinite loops and runaway recursion gracefully (`Time Limit Exceeded`).
- **Inline Diagnostics:** Compiler errors and warnings are parsed directly into line and column highlights rather than walls of console text.
- **Smart Binary Caching:** SHA-256 binary caching gives instantaneous zero-latency execution on unchanged code blocks.
- **Web Playground:** Try it directly in your browser without installing anything at [RunCplus Live Playground](https://run-cplus-playground.go.altare.global).
