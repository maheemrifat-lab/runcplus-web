Built for momentum

Everything an IDE does.
None of the waiting.

Traditional editors make you save, compile, run, repeat. RunCplus collapses that loop.

Instant auto-run

A 500 ms debounce compiles in the background while you type, so the answer is already waiting.

Inline diagnostics

Compiler errors are parsed into line and column markers, not a wall of stderr text.

Watchdog sandbox

Runaway loops and infinite recursion are terminated at 2 seconds — your session never hangs.

Binary cache

SHA-256 content hashing skips recompilation of unchanged code, returning results in 0 ms.

Desktop & Android

A native Qt 6 desktop IDE and a mobile companion app share the same engine and theme.

Zero-setup cloud

No compilers to install, no PATH to fix. Open a tab and write C++ on any machine.

Questions

Frequently asked

What RunCplus is, who builds it, and how to get it.

Is there a C and C++ app made by Md Mahim Islam?

Yes. RunCplus is a live C and C++ IDE and compiler created and founded by Md Mahim Islam (CSE), Institute of Science and Technology (IST). It is available as a free desktop app for Windows, macOS and Linux, an Android APK, and a browser playground.

Who created RunCplus?

RunCplus was designed, engineered and is maintained by Md Mahim Islam, a Computer Science and Engineering student at the Institute of Science and Technology (IST). He is the founder and lead creator of the project.

Is RunCplus free to download?

Yes. RunCplus is free, requires no account or sign-in, and every platform gets a single installer file with no ZIP archives: a Windows .exe setup, a macOS .dmg, a Linux .AppImage and an Android .apk.

Which platforms does RunCplus run on?

RunCplus runs on Windows 10 and 11 (x64), macOS 12 or newer on Apple Silicon, Linux x86_64, Android 8.0 and newer, and in any modern web browser.

What makes RunCplus different from other C++ IDEs?

RunCplus compiles and runs your code the moment you stop typing, using a 500 ms debounce, SHA-256 binary caching and a watchdog sandbox that safely kills infinite loops. Compiler errors appear inline on the exact line instead of in a console wall of text.

How do I download RunCplus?

Open the Downloads section of this page and choose your platform, or grab the files directly from the official GitHub release. Each download is a single file that installs or runs immediately.
